# AI感情翻訳ツール

国際恋愛における感情を英語に翻訳するAIツール

## 機能

- 日本語で状況を入力
- FINR法に基づいた英語文章を自動生成
- スマホ対応のシンプルなUI

## 技術スタック

- Next.js 14
- React 18
- Anthropic Claude API (Sonnet 4)
- Vercel (デプロイ)

## セットアップ

1. リポジトリをクローン
2. `npm install`
3. 環境変数 `ANTHROPIC_API_KEY` を設定
4. `npm run dev` で開発サーバー起動

## デプロイ

Vercelで自動デプロイ

環境変数:
- `ANTHROPIC_API_KEY`: Anthropic APIキー

## ライセンス

Private
